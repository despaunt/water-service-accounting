# Учёт отпуска услуг водоканала

Лабораторная работа 4 по командному проектированию и разработке. Учебная конфигурация для платформы 1С:Предприятие 8.3.27, со встроенным языком BSL и отдельной файловой информационной базой. В рабочем проекте ВКР аналогичные объекты планируется использовать в 1С:Комплексной автоматизации. Здесь один документ соответствует одной услуге по одному объекту за период.

- `app/models/Catalogs` — справочники договоров, объектов расчётов и услуг.
- `app/models/Documents/РасчетОтпускаУслуг.xml` — модель расчёта, ссылки на объект и услугу, период, объём, тариф и сумма.
- `app/models/CommonModules/РепозиторийРасчетов/Ext/Module.bsl` — создание, чтение, выборка по периоду, изменение объёма и тарифа, пометка на удаление. Использую объектную модель и запросы 1С, поэтому устанавливать отдельную ORM и обращаться к таблицам СУБД напрямую не требуется.

В этой версии можно создать расчёт в отдельной пустой базе и проверить сумму. Начальные данные вымышленные.
